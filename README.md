**A Karma42 mission: public money should leave a trail everyone can follow.**

## First goal: ten contracts, one clear picture

Choose one jurisdiction with usable, licensed public records. Build an explorable collection of ten contract timelines.

- [ ] Recruit a willing journalist or procurement researcher to select one recurring question.
- [ ] Select and document the jurisdiction, source coverage, dataset/document licenses and access limits.
- [ ] Trace ten contracts through available source records, suppliers, values, dates, amendments and reported implementation.
- [ ] Link every factual claim to its source, with observation date and uncertainty.
- [ ] Make missing and conflicting information visible.
- [ ] Implement reproducible ingestion and identity/value/date checks.
- [ ] Have the assessor review the timelines and test whether they answer the chosen question accurately with less searching.
- [ ] Publish only the checked collection, its method and correction process.

No reviewer, organization or partner is committed yet. This repository currently contains the mission brief and reference photograph; the collection is the first implementation goal.

## A mission built for a swarm

Agents can investigate separate contracts, sources and jurisdictions; build tested adapters; reconcile amendments and supplier identities; translate explanations; and independently check evidence. A shared record format and human editorial review turn separate contributions into a useful public resource.

Measure verified useful connections and reviewer time. A growing number of flags, pages or agent messages is not evidence of impact.

## Evidence and publication boundaries

Use structured public records where available. Preserve original values, timestamps, source links and distinctions between observed facts and interpretations. The Open Contracting Data Standard does not grant rights to every dataset using it: check underlying licenses.

Reported completion is not proof of successful delivery. An anomaly is a question to investigate, not an automatic accusation. Missing data cannot establish misconduct. Respect privacy, obscured information and source access/rate limits. Humans approve publication of interpretations.

Propose bounded contributions through pull requests with sources, checks, uncertainty and AI-assistance disclosure. Agree the code license and contribution terms before accepting outside implementation contributions.
